# Smart-City-Magdeburg-Dashboard

What should be developed? 
The technology stack, tools, and thematic focus of your "Smart City" dashboard are entirely up to you. The important thing is that it demonstrates added value for Magdeburg. Feel free to draw inspiration from best practice examples in other smart cities references.

The goal should be for you/your team to be able to present a prototype of a “Smart City” dashboard in a short public pitch to the jury and the audience at Tomorrow Labs after 24 hours .
